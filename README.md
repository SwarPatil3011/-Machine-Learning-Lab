# Machine Learning Lab – Practical Implementations

## 📌 About the Project

This repository contains the implementation of various Machine Learning algorithms using Python and Scikit-learn. These practicals demonstrate different machine learning techniques, including regression, classification, and clustering.

The experiments were performed using Jupyter Notebook.

## 🎯 Algorithms Implemented

The following Machine Learning algorithms have been implemented:

1. Linear Regression
2. Decision Tree Classification
3. K-Nearest Neighbors (KNN)
4. K-Means
5. Random Forest Classification
6. Support Vector Machine (SVM)
7. Naive Bayes Classification
8. Perceptron

## 📊 Dataset Information

### 1. Diabetes Prediction Dataset

The diabetes prediction dataset contains 27,528 records and 9 columns.

**Features:**
- Gender
- Age
- Hypertension
- Heart Disease
- Smoking History
- BMI
- HbA1c Level
- Blood Glucose Level

**Target Variable:**
- Diabetes (0 = No Diabetes, 1 = Diabetes)

This dataset is used for classification algorithms and K-Means clustering.

### 2. Salary Dataset

The Salary dataset is used for implementing Linear Regression to study the relationship between years of experience and salary.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Launch Jupyter Notebook or JupyterLab.
4. Open the required `.ipynb` file.
5. Run the notebook cells sequentially.
6. Observe the model outputs, evaluation metrics, and visualizations.

## 📈 Model Evaluation

The classification algorithms are evaluated using:

- Accuracy Score
- Confusion Matrix
- Precision
- Recall
- F1-Score
- Classification Report

K-Means clustering is evaluated using clustering results and the Silhouette Score.

## 🎓 Objective

The objective of this project is to understand and implement different Machine Learning algorithms, perform data preprocessing, train models, make predictions, and evaluate their performance using Python.
